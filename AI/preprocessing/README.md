#  데이터 전처리 파이프라인 (Data Preprocessing Pipeline)

본 문서는 모델 학습 및 검증, 추론 시 이미지 데이터에 일관되게 적용되어야 하는 전처리 파이프라인 규격을 정의

##  주요 파라미터 상수

ImageNet 사전 학습 모델(Pre-trained Model)의 규격을 따릅니다.

* **입력 이미지 크기 (CROP_SIZE):** `224 x 224`
* **여유 공간 확보용 리사이즈 (RESIZE_SIZE):** `256 x 256`
* **정규화 평균 (NORMALIZE_MEAN):** `[0.485, 0.456, 0.406]` (RGB 순서)
* **정규화 표준편차 (NORMALIZE_STD):** `[0.229, 0.224, 0.225]` (RGB 순서)

---

## 전처리 단계별 상세 설명

이미지의 형태 왜곡을 방지 및 핵심 질감 정보를 보존하기 위해 **패딩(Padding) 기반의 전처리 방식**을 채택

### 1. 학습용 파이프라인 (Train Pipeline)
데이터의 다양성을 확보하기 위해 무작위성을 부여하는 증강(Augmentation) 기법이 포함

1.  **Square Padding (비율 유지):** 이미지의 가로/세로 원본 비율을 무너뜨리지 않도록, 짧은 쪽의 빈 공간을 검은색(픽셀값 0)으로 채워 **1:1 정사각형**으로 조정
2.  **Resize:** 정사각형이 된 이미지를 찌그러짐 없이 `256 x 256` 크기로 조절
3.  **Random Crop (증강):** `256 x 256` 크기의 이미지 내에서 `224 x 224` 크기로 무작위 위치를 크롭
4.  **Random Horizontal Flip (증강):** 50%의 확률로 이미지를 좌우 반전
5.  **To Tensor & Scale:** 이미지를 텐서(Tensor)로 변환, 픽셀 값을 `0 ~ 1` 사이로 스케일링
6.  **Normalize:** 명시된 Mean, Std 값을 사용하여 ImageNet 규격에 맞게 정규화

### 2. 검증/테스트 및 추론 파이프라인 (Val/Test/Inference Pipeline)
모델 성능 평가의 공정성을 위해 무작위성을 배제

1.  **Square Padding:** 학습과 동일하게 빈 공간을 검은색으로 채워 1:1 정사각형으로 조정
2.  **Resize:** `256 x 256` 크기로 리사이즈
3.  **Center Crop:** 항상 정중앙을 기준으로 `224 x 224` 크기로 크롭 (랜덤성 배제)
4.  **To Tensor & Scale:** 픽셀 값을 `0 ~ 1` 사이로 스케일링
5.  **Normalize:** 동일한 규격으로 정규화
