# 쓰레기 분류 클래스 정의 (Garbage Classes)

본 문서는 쓰레기 이미지 분류 모델 학습을 위해 정의된 10가지 클래스 목록을 정리한 문서입니다.

## 클래스 목록

|  | 클래스명 (Class) | 설명 및 분류 기준 (예시) |
| :---: | :--- | :---: |
| 1 | **Clothes** | 의류, 헌 옷, 천이나 직물류 |
| 2 | **Glass** | 유리병, 깨진 유리 등 유리류 |
| 3 | **Plastic** | 페트병, 플라스틱 용기, 비닐 및 포장재 |
| 4 | **Shoes** | 운동화, 구두, 슬리퍼 등 신발류 |
| 5 | **Cardboard** | 택배 상자, 골판지처럼 두꺼운 종이류 |
| 6 | **Paper** | 일반 종이, 신문지, 영수증, 노트 등 종이류 |
| 7 | **Metal** | 알루미늄 캔, 고철, 철사 등 금속류 |
| 8 | **Battery** | 폐건전지, 보조배터리 등 배터리류 |
| 9 | **Biological** | 음식물 쓰레기, 나뭇잎 등 유기성 폐기물 |
| 10 | **Trash** | 위 항목에 해당하지 않는 일반 쓰레기 |
